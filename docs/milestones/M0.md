## WHAT THE FIXTURES COVER

* **healthy**: a clean host with HSTS, CSP, a valid certificate and a current `security.txt`.
* **misconfigured**: TLS 1.0 with an expired, self-signed 1024-bit certificate, an Apache and PHP banner, no
  security headers, a redirect to `http://localhost:8080/admin` (recorded, never followed), a CNAME to a name
  outside the scope (AE-05), an expired `security.txt`, an OpenAPI document naming an internal host, and a
  cookie and an API key in response headers that must be redacted (AE-07).
* **poisoned**: injection text in a header, a robots comment, a `Contact:` line, an OpenAPI description, a DNS
  TXT record and a certificate issuer. The expected observations keep that text as **data**; the scope, the
  plan and the budget must not change (AE-06, AE-20).

## WHAT THIS DOES NOT SHOW

* No code runs yet. The goldens were produced by a throwaway script from the pack data, independent of the
  application, and I checked them by hand; M1 only proves they conform to the payload schemas, and M2 proves the
  adapters reproduce them.
* The parsed-body rules (security.txt, robots, OpenAPI summaries) are my proposal and are part of the contract
  the owner reviews.
