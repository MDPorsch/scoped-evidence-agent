## WHAT TESTING FOUND IN MY OWN WORK

* **A real bug in M2, found by the new fixture.** Redaction by header name replaced `Access-Control-Allow-Credentials: true` (the name
  contains "credential"), so the credentials branch of rule R-CORS-01 could never fire on stored data and a CORS review lost the one fact it
  needs. Fixed for that exact name only (D-E72), with a regression test through the real pipeline that fails without the fix.
* **A hostile spec document carries a sentence in its title.** The spec is stored as an artifact (it holds no response value), and a test
  shows its text reaches no table and no observation field; only the artifact holds it, as the document it is.
* **Layered checks hid each other.** The path-template check and the params-must-match-the-path check both refused a bad path, so removing
  either alone changed nothing (the mutation run found it). The tests now also give a bad path no params list, so only the path rule can refuse it.
