## WHAT TESTING FOUND IN MY OWN WORK

* **A real bug (Hypothesis):** a NUL byte in a scope file crashed the loader with a raw YAML error instead of `SCOPE-001`. PyYAML checks
  characters in its constructor, which sat outside my `try`. Fixed, with a regression test.
* **The alias check was never exercised.** Every alias in my tests came with an anchor, and the anchor check fires first. A bare `*x` reaches it.
* **28 mutants survived the first run, 4 more after the AI code.** Each was a gap in a test, not in the code: a depth cap tested only
  at 40 levels, a restrictive `umask` never tried, a failed run's `ended_at` never checked after a retry, an audit `decision` value
  never asserted, a flag tested for one key of four, an "errors ignored" bug that only a lucky Hypothesis draw caught. All now have an
  explicit test and die. Two mutants were removed as provably equivalent (two layers guard the same property); each is noted in the table.
* **A design flaw in my own doc:** the AI-target contract listed `paths` as well as `metadata_paths` and `probe_path`, which could grant a
  path no operation used. Removed before any code existed.
* **My tests were sloppy in places** (a count off by one, a test that repeated a transition, one that re-seeded a database each loop).
  The code caught the second kind and the test runs caught the others. Nothing was weakened to pass.

## WHAT THIS DOES NOT SHOW

* **Nothing collects data yet.** There are no adapters (M2), no correlator or reports (M3), no model (M4), and live mode is approved
  but not built (M5, last).
* **No AI system has been contacted.** The probe library holds ids, categories and counts; the probe texts arrive with the adapters.
* **Redaction of observations is not built** (M2). Today the artifact store only accepts content marked redacted.
* **The audit chain cannot detect the loss of its newest events**, and observation rows are not hash-chained (LIMITATIONS SE-11, SE-12).
* **Mutation testing shows the tests notice these bugs, not that no other bug exists.**
