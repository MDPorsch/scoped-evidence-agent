## WHAT TESTING FOUND IN MY OWN WORK

* **A hostile target could stop drafting.** A hostile pack that put a long host or banner in every field made one quoted fact exceed the
  80-character schema limit, and the whole run ended `FAILED`. A fact is now quoted only when the finished text fits, and titles and
  conditions are bounded. Regression tests, and mutants that restore each bound.
* **My first mutation run left 89 of 510 new mutants alive.** 76 were gaps in my tests: a template sentence never asserted, a Markdown
  special character never fed through the escaper, a trimmed or case-folded header never tried, a SQL `LIKE` wildcard that only differed
  from a literal at one position, an ordering that only looked right by luck, a coverage edge. Each now has an explicit test, and the step
  templates are pinned by a reviewed snapshot. Four guarded a property twice (a step limit, a decision-guide check, a probe's target and
  its operations); they now remove both layers, as in M1 and M2, and die. Nine were taken out of the table with a note: six layered (a
  size limit checked by the checker and again by the step model, a port range refused by the checker and by the strict `StepTarget`, a
  report path that is a symbolic link or an existing file refused three ways), one equivalent (a step may cite an id no rule ever cites), and
  two were dead code (`urlsplit` already lower-cases a scheme and the payload host is already canonical), so I removed the code.
* **Wrong tests of mine, caught by the code:** I expected a draft to start at revision 1 (it is 2: created, then moved to review), counted
  five CHECK constraints on reviews (four), and wrote a Hypothesis input the payload schema rightly refused.
* **A sloppy-test habit:** several first drafts of tests had placeholder assertions or convoluted conditions; I rewrote them before
  they were committed. Nothing was weakened to pass.
* **A paper cut:** the Markdown said `ended None` for a run that had not ended. It now says `not ended`.

## WHAT THIS DOES NOT SHOW

* **Nothing has touched a network, and no rule has met a real server.** The packs are mine. The rules are only as good as what I thought a
  misconfiguration looks like.
* **Twelve rules are not a scanner.** No draft is not proof that nothing is wrong (SE-24). Confidence is a table value, not a probability
  (SE-26).
* **A validation step is text.** The tool runs none, and `rerun_library_probe` and `check_cors_for_declared_origin` cannot be acted on in
  0.x (SE-31).
* **Identity is typed** (SE-28), and a report names the reviewer and shows their redacted reason (SE-29).
* **Mutation testing shows the tests notice these bugs, not that no other bug exists.**
